# Timer

ビルド不要・依存関係なしの、単一 HTML ファイルで動くタイマーアプリです。

## 使い方

`index.html` をブラウザで開くだけで動作します。

```
open index.html
```

ダブルクリックでも、ローカルサーバー (`python -m http.server`) でもOKです。

## 機能

- カウントダウンモード：分・秒の入力とプリセットボタン（1 / 3 / 5 / 10 / 15 / 30 分）
- カウントアップモード：00:00 から上限なしで計測（1分ごとにリングが1周、1時間以上は `h:mm:ss` 表示）
- 円形プログレスバーによる時間の表示
- スタート / 一時停止 / 再開 / リセット
- 時間終了時の通知音（Web Audio API）とデスクトップ通知
- タブのタイトルに残り時間を表示
- `performance.now()` ベースの計測なので、バックグラウンドでもズレにくい

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Space` | 開始 / 一時停止 |
| `R` | リセット |

## ブラウザ

最新の Chrome / Edge / Firefox / Safari を想定しています。
音や通知が使えない環境でも、タイマー本体は動作します。
